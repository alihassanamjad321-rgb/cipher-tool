# Cipher Tool Website

A simple web-based tool to encrypt and decrypt text using classical ciphers.  
This project demonstrates basic cryptography concepts through an interactive web interface.

## Features
- Encrypt and decrypt text using **Caesar Cipher** (or other ciphers if implemented)  
- Clean, responsive web interface using HTML & CSS  
- Easy-to-use input and output fields  
- Optional: choose cipher shift/key (for Caesar)  

## Files Included
- `index.html` – main web page  
- `style.css` – styles for the website  
- `script.js` (optional) – JavaScript functionality  
- `README.md` – this file  

## How to Run Locally
1. Clone this repository:
    ```bash
    git clone https://github.com/yourusername/cipher-tool-website.git
    cd cipher-tool-website
    ```
2. Open `index.html` in your browser (no server needed for basic HTML/CSS/JS).
